# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。

## 尚未判断的影响

影响值区分两种“零”：滑块给到 `0` 表示**已判断为中性**；每个维度另有「尚未判断」开关，标记后该格不参与评分（滑块数值会被保留，切回来原样恢复）。分析时：

- 相关维度（权重 > 0）全部已判断才给出确定建议；否则未知维度按 `+5 / −5` 两个极端假设生成**最好 → 最差区间**（曲线色带、总分区间），绝不把未知当 0，也不自动忽略。
- 若领先方案在自己最差情形下仍领先 ≥5 分，给出**条件性建议**；否则**阻止正式建议**，只展示临时区间与可追溯的缺口清单，补齐后重新推演。
- 排序在有缺口时按各方案的最差情形（maximin）进行，未知多的方案不会因缺少负面数据而占优。
- 旧案例保存的数字影响（含 0）迁移后一律视为已判断，0 仍代表原来的中性；缺口完整度会随案例保存、重新打开和打印保留。
