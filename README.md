# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。

## 未判断影响（与中性 0 区分）

- 滑块在 `0` 表示**已判断为中性**；新增方案的每个维度默认是「未判断」，也可随时手动切换。两种状态分别保存，切换回已知时恢复此前输入，不会重置成 0。
- 未判断维度的影响可能是 -5 到 +5 的任意值，评分时给该维度贡献区间 `[0, 权重×时间系数]`，每个时间点和总分都显示「最小–最大可能后悔」，曲线以虚线区间带表示，绝不把未知当 0 或静默忽略。
- 结论分三档：
  - `complete`：所有维度已判断（含前两名接近、按原规则不强推的情形）；
  - `robust-with-gaps`：存在缺口，但领先者**最坏情况**仍比每个对手**最好情况**好至少 5 分，正式建议不受影响；
  - `provisional`：缺口可能改变比较结果——阻止正式推荐，只给按最坏情况（minimax）的临时排序，并逐条列出哪些方案的哪些维度在阻塞结论。
- 临时排序按最坏可能后悔升序：未知越多最坏分越高，方案不会因缺少负面数据而占前排。结果页与打印报告均标注完整度、区间与条件性预演卡；缺口补齐后重新计算即收敛为确定分数。
- 旧案例（无 `unknownImpacts` 字段）加载时自动迁移为「全部已知」，原有 0 仍代表中性，旧版分析结果会用迁移后的草稿重算且分数不变。
